# 🇷🇺 Инструкция по размещению сайта «ВОЗДУХ НСК» на российских серверах (152-ФЗ РФ)

Проект полностью подготовлен для автономной работы на территории Российской Федерации и соблюдения требований **Федерального закона № 152-ФЗ «О персональных данных» (ч. 5 ст. 18 — локализация баз данных в РФ)**.

---

## 1. Что уже встроено в проект для соблюдения законов РФ

1. **Никаких зарубежных запросов из браузера посетителя:**
   - Отключены внешние обращения к зарубежным серверам `fonts.googleapis.com` и `images.unsplash.com` (Роскомнадзор трактует прямые запросы браузера к американским CDN как трансграничную передачу IP-адресов граждан РФ).
   - 100% фотографий, SVG-иконок, логотипов и стилей отдаются напрямую с вашего российского сервера.
2. **Физическое сохранение всех заявок на российском сервере (`data/`):**
   - Встроенный сервер `server.js` и шлюз `api/lead.js` автоматически сохраняют каждую заявку, анкету партнёра, параметры калькулятора и сгенерированное ТЗ на диск вашего российского сервера в два файла:
     - `data/leads.csv` — готовая таблица для **Microsoft Excel / МойОфис / 1С** (в кодировке UTF-8 с BOM, открывается на русском языке двойным кликом).
     - `data/leads.jsonl` — полная структурированная база данных всех заявок.
   - Скачать актуальную таблицу всех заявок в Excel можно в любой момент по защищённой ссылке:
     `https://vozduh-nsk54.ru/api/leads-export?key=ВАШ_ADMIN_EXPORT_KEY`
3. **Юридические документы и плашка согласия (152-ФЗ):**
   - На сайте размещена полная **Политика обработки персональных данных ООО «ВОЗДУХ НСК»** (ИНН `5405074634`, ОГРН `1225400025190`) — доступна как в модальном окне, так и по прямой ссылке `/privacy-policy.html` (для автоматических проверок Роскомнадзора).
   - Во все формы обратной связи добавлены кликабельные ссылки на Политику ПДн (152-ФЗ), а при первом входе отображается уведомление об использовании технических файлов cookie на серверах в РФ.
4. **Российский ИИ (YandexGPT):**
   - Инженерный консультант и генератор ТЗ работают через **Yandex Cloud (`llm.api.cloud.yandex.net`)**, чьи дата-центры расположены в РФ.

## 2. Вариант А (Самый быстрый — за 5 минут): Timeweb Cloud App Platform (Дата-центр: Санкт-Петербург / Москва / Новосибирск)

Если вы не хотите вручную настраивать Linux-сервер, в **Timeweb Cloud** (крупнейший российский облачный провайдер с аттестатом соответствия 152-ФЗ УЗ-1) есть автоматический деплой прямо из вашего GitHub:

1. Зарегистрируйтесь или войдите на [timeweb.cloud](https://timeweb.cloud).
2. В левом меню выберите **Cloud Apps (Приложения)** → **Добавить** → **Полноценное приложение (Backend + Frontend)** или **Docker / Node.js**.
3. Подключите ваш аккаунт **GitHub** и выберите репозиторий `nikma27/vozduh-preview2` (ветка `main`).
4. Выберите локацию сервера: **Россия (Новосибирск, Москва или Санкт-Петербург)**.
5. Если выбран тип **Docker**, Timeweb автоматически прочитает `Dockerfile` из корня проекта и запустит `server.js` на порту `3000`.
   Если выбран тип **Node.js (22)**:
   - Команда сборки: `npm ci && npm run build`
   - Команда запуска: `npm start`
   - Порт: `3000`
6. Во вкладке **Переменные окружения** добавьте:
   - `ADMIN_EXPORT_KEY` — придумайте надёжный пароль для скачивания таблицы заявок в Excel.
   - `YANDEX_FOLDER_ID` и `YANDEX_API_KEY` — ключи от вашего каталога в Яндекс Облаке (для AI-консультанта).
   - `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID` — (по желанию) для дублирования заявок в ваш Telegram.
7. Во вкладке **Домены** привяжите ваш домен `vozduh-nsk54.ru` — бесплатный SSL-сертификат Let's Encrypt выпустится автоматически!

## 3. Вариант Б: Свой облачный сервер (VPS) в РФ (Timeweb Cloud / Selectel / Рег.ру / Яндекс Облако)

Если вы арендуете виртуальный сервер (VPS с Ubuntu 22.04 / 24.04) в российском дата-центре:

### Шаг 1. Подключитесь к серверу по SSH и скачайте проект
```bash
sudo apt update && sudo apt install -y git docker.io docker-compose-v2 nginx certbot python3-certbot-nginx
git clone https://github.com/nikma27/vozduh-preview2.git /var/www/vozduh-nsk
cd /var/www/vozduh-nsk
cp .env.example .env
nano .env
```

### Шаг 2. Запустите сайт и локальную базу заявок одной командой
```bash
sudo docker compose -f docker-compose.ru.yml up -d --build
```
Сайт запустится на `127.0.0.1:3000`, а все заявки посетителей будут сохраняться на диске сервера в папке `/var/www/vozduh-nsk/data/leads.csv` и `/var/www/vozduh-nsk/data/leads.jsonl`.

### Шаг 3. Подключите домен `vozduh-nsk54.ru` и HTTPS-шифрование
1. В панели вашего регистратора домена (Рег.ру / Руцентр / Timeweb) укажите в DNS `A`-запись домена `vozduh-nsk54.ru` и `www.vozduh-nsk54.ru` на IP-адрес вашего российского сервера.
2. Скопируйте готовую конфигурацию Nginx и выпустите SSL-сертификат:
```bash
sudo cp /var/www/vozduh-nsk/nginx/vozduh-nsk54.conf /etc/nginx/sites-available/vozduh-nsk54.conf
sudo ln -s /etc/nginx/sites-available/vozduh-nsk54.conf /etc/nginx/sites-enabled/
sudo certbot --nginx -d vozduh-nsk54.ru -d www.vozduh-nsk54.ru
sudo systemctl reload nginx
```
fінальная проверка работы сервера: откройте `https://vozduh-nsk54.ru/api/health` — сервер ответит `{"ok":true,"service":"vozduh-nsk-ru","compliance":"152-FZ-RF"}`.
